# プレゼミ 学習ノート

プレゼミ生向けの研究体験用の教材サイトです。トップページは `index.html`（研究の流れ）です。

| ファイル | 内容 |
|---|---|
| `index.html` | 研究の流れ |
| `00-setup.html` | 第0回 はじめる準備 |
| `01-web.html` | 第1回 Webのしくみ |
| `02-git.html` | 第2回 Git と GitHub |
| `03-python.html` | 第3回 Python で Web サイトを作る |
| `04-research-system.html` | 第4回 研究データを集めるシステム |
| `05-report.html` | 第5回 レポートの書き方 |

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリの直下に置いて push する
2. GitHub のリポジトリ画面で「Settings」→「Pages」を開く
3. 「Branch」で `main` と `/ (root)` を選んで「Save」
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で表示される

チェックの記録は、見ている人のブラウザにページごとに保存されます。
