Overview

全体の流れ

これから使う道具は、次のような関係になっています。書く、命令する、動かす・記録する、共有する、の順番です。

1 / 4道具の関係

Part 1

道具をそろえる

第1回〜第3回で使うソフトとアカウントを準備します。授業の前に済ませておきましょう。

Step 1/ 10

このシリーズで使う道具

プログラミングを始めるには、いくつかの道具が必要です。どれも無料で使えます。

道具役割使うレッスン
VS Codeプログラムやファイルを書くエディター全部
ターミナル文字で PC に命令する画面（最初から入っている）全部
Pythonプログラミング言語と、それを動かすソフト第3回
Git変更を記録するバージョン管理ツール第2回・第3回
GitHub アカウント記録を共有・公開する Web サービスのアカウント第2回・第3回
Google Chrome開発者ツールで通信を観察するブラウザ第1回

補足

この資料は、Windows 10・11 と Mac を想定しています。OS によって手順が違うところは、両方を書いています。

ポイント

インストールは時間がかかることがあります。授業の当日ではなく、事前に済ませておくのがおすすめです。

次へ：VS Code を入れる

Step 2/ 10

VS Code を入れる

VS Code（Visual Studio Code）は、Microsoft が作っている無料のエディターです。プログラムを書く、ファイルを整理する、ターミナルを開く、Git を操作する、がすべて1つの画面でできます。

  1. 公式サイト（code.visualstudio.com）からダウンロードして、インストールする
  2. 起動したら、左の「拡張機能」アイコンから Japanese Language Pack を入れて、日本語表示にする
  3. 同じく拡張機能の Python（Microsoft 製）を入れる
よく使う操作WindowsMac
フォルダを開くファイル → フォルダーを開くファイル → 開く
ターミナルを開くCtrl + `（日本語キーボードは Ctrl + @）Ctrl + `（日本語キーボードは Ctrl + @）
保存するCtrl + S⌘ + S
コマンドパレット（なんでも検索）Ctrl + Shift + P⌘ + Shift + P

ポイント

VS Code は「フォルダを開いて」使うのが基本です。ファイルを1つずつ開くより、プロジェクトのフォルダごと開くと、左側に中身が一覧で表示されて便利です。

補足

Mac でターミナルから code . と打って VS Code を開けるようにするには、コマンドパレットで「Shell Command: Install 'code' command in PATH」を実行します。Windows はインストール時に自動で設定されます。

次へ：Python を入れる

Step 3/ 10

Python を入れる

Python の公式サイト（python.org）の「Downloads」から、最新版をダウンロードしてインストールします。

注意

Windows の場合：インストール画面の最初にある「Add python.exe to PATH」に必ずチェックを入れてください。忘れると、ターミナルで python と打っても動きません。

インストールできたら、ターミナルで確かめます。

Mac
$ python3 --version
Python 3.13.0
Windows
$ python --version
Python 3.13.0

補足

Mac では python3、Windows では python（または py）と打つのが一般的です。数字は入れた時期によって変わります。3 から始まっていれば大丈夫です。

次へ：Git を入れる

Step 4/ 10

Git を入れる

Git は、第2回で使うバージョン管理ツールです。

OS入れ方
Windows公式サイト（git-scm.com）から「Git for Windows」をダウンロードしてインストールする。設定はすべて最初の選択のままで大丈夫
Macターミナルで git --version と打つ。入っていなければインストールの案内が出るので、それに従う
確認
$ git --version
git version 2.47.0

最後に、記録に残る名前とメールアドレスを設定します。メールアドレスは、次の Step で GitHub に登録するものと同じにしておきます。

最初に一度だけ
git config --global user.name "あなたの名前"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main

3行目は、最初に作られる「枝」の名前を main にする設定です。GitHub の標準に合わせておくと、第2回で push するときにつまずきません。

補足

Git for Windows には「Git Bash」というターミナルも入っています。Mac と同じコマンドが使えるので、Windows の人はこちらを使ってもかまいません。

次へ：GitHub のアカウントを作る

Step 5/ 10

GitHub のアカウントを作る

GitHub の公式サイト（github.com）の「Sign up」から、メールアドレスで登録します。

  1. メールアドレス・パスワード・ユーザー名を決めて登録する
  2. 届いたメールの確認コードを入力する
  3. 案内に従って二段階認証を設定する（スマホの認証アプリなど）

注意

ユーザー名は、公開ページの URL（https://ユーザー名.github.io/）にもなり、世界中から見えます。本名でなくてかまいません。あとから変えることもできますが、URL も変わるので、最初によく考えて決めましょう。

ポイント

学生は「GitHub Education」に申し込むと、有料の機能や開発ツールを無料で使えるようになります。学生証などで認証が必要です。

次へ：ターミナルとは

Part 2

ターミナルの基本

文字で PC に命令する「ターミナル」の使い方を覚えます。

Step 6/ 10

ターミナルとは

ふだん私たちは、マウスでアイコンをクリックして PC を操作しています（GUI）。ターミナルは、それを文字の命令（コマンド）で行う画面です（CLI）。

GUI（マウス）CLI（ターミナル）
操作アイコンをクリックコマンドを打って Enter
得意なこと見ながら直感的に操作同じ作業のくり返し、細かい指定、自動化
プログラミングではファイルを開く・見るプログラムを動かす、Git を使う、ライブラリを入れる

ターミナルの開き方です。迷ったら、VS Code の中のターミナル（メニューの「表示 → ターミナル」）を使えば、OS の違いを気にせずにすみます。

OSアプリ
Mac「ターミナル」（アプリケーション → ユーティリティ）
Windows「ターミナル」または「PowerShell」。Git を入れた人は「Git Bash」も使える
ターミナルを開いたところ（Mac の例）
hanako@MacBook ~ %

最後の %（Windows では >、Git Bash では $）はプロンプトといって、「命令を待っています」という合図です。この資料では、入力する行の先頭に $ を付けて表しています。$ そのものは打ちません。

たとえると

GUI がレストランのメニューの写真を指さして注文すること、CLI が店員さんに言葉で注文することです。慣れると、言葉のほうが細かく、速く伝えられます。

次へ：場所の考え方：フォルダとパス

Step 7/ 10

場所の考え方：フォルダとパス

ターミナルで一番大事なのは、「いま、どのフォルダにいるか」を意識することです。ターミナルは常にどこか1つのフォルダの中にいて、そこをカレントディレクトリ（現在地）といいます。

1 / 7フォルダの移動
用語意味例
ディレクトリフォルダのことDocuments
パスフォルダやファイルの場所を表す住所/Users/hanako/Documents/presemi
ホーム（~）自分専用のフォルダ。ターミナルを開いたときの場所Mac: /Users/hanako、Windows: C:\Users\hanako
..1つ上のフォルダcd .. で戻る
.いまいるフォルダcode . で、いまの場所を VS Code で開く

補足

Mac のパスは / で、Windows のパスは \ で区切ります。PowerShell では / も使えます。

ポイント

迷子になったら pwd でいまの場所を、ls で周りを確認しましょう。地図アプリの「現在地」ボタンと同じです。

次へ：基本のコマンド

Step 8/ 10

基本のコマンド

まずはこの表のコマンドだけで十分です。打ったコマンドの結果がどう反映されるか、アニメーションで確かめましょう。

1 / 6ファイルの操作
コマンド意味例
pwdいまの場所を表示pwd
ls中身を一覧表示ls
cd場所を移動cd presemi
mkdirフォルダを作るmkdir web
touch空のファイルを作るtouch memo.txt
cpコピーcp memo.txt copy.txt
mv移動・名前の変更mv memo.txt web/
rm削除rm memo.txt
catファイルの中身を表示cat memo.txt
clear画面をきれいにするclear

補足

Windows の PowerShell でも、ほとんどのコマンドはそのまま使えます。touch だけは使えないので、代わりに New-Item memo.txt と打ちます。Git Bash ならすべて同じです。

注意

rm で消したファイルはゴミ箱に入らず、すぐに消えます。フォルダごと消す rm -r は特に慎重に。打つ前に、pwd と ls で場所と中身を確かめましょう。

理解度チェック

いまいるフォルダの「1つ上」に戻るコマンドは？

.. は1つ上、~ はホーム、. はいまの場所です。

次へ：覚えておくと楽になるワザ

Step 9/ 10

覚えておくと楽になるワザ

ターミナルの操作がぐっと楽になるワザです。最初から使うクセをつけましょう。

ワザ操作効果
補完Tabファイル名の途中まで打って押すと、残りを自動で入力してくれる。打ち間違いも防げる
履歴↑ ↓前に打ったコマンドを呼び出す
止めるCtrl + C動きっぱなしのプログラム（Flask のサーバーなど）を止める
場所をドラッグフォルダをターミナルにドラッグそのフォルダのパスが入力される
VS Code で開くcode .いまいるフォルダを VS Code で開く

注意

フォルダやファイルの名前には、半角の英数字を使いましょう。日本語やスペースが入っていると、コマンドで扱うときにエラーの原因になります。「プレゼミ 資料」ではなく「presemi」のように。

ポイント

ターミナルで Ctrl + C はコピーではなく「止める」です。コピーしたいときは、Mac では ⌘ + C、Windows のターミナルでは文字を選んで Ctrl + Shift + C を使います。

次へ：よくあるつまずきと直し方

Part 3

困ったときは

エラーが出ても慌てないための、よくある原因と直し方です。

Step 10/ 10

よくあるつまずきと直し方

エラーは失敗ではなく、「ここがおかしいよ」という PC からのメッセージです。よくあるものと、直し方をまとめました。

表示されたメッセージ（例）よくある原因直し方
command not found: python3
用語 'python' は…認識されません		インストールされていない、または PATH が通っていないもう一度インストールする（Windows は PATH のチェックを忘れずに）。そのあとターミナルを開き直す
python と打つと Microsoft Store が開くWindows の「アプリ実行エイリアス」が働いているpython.org から入れたうえで、設定の「アプリ実行エイリアス」で Python をオフにする
No such file or directoryいる場所が違う、名前の打ち間違いpwd と ls で場所と名前を確かめる。Tab 補完を使う
pip: command not foundpip のコマンドが見つからないpython3 -m pip install ... のように Python 経由で使う
Permission deniedそのファイルを触る権限がない自分のホームの中で作業しているか確かめる。わからなければ先輩・先生に相談
何も起きない・戻ってこないプログラムが動き続けているCtrl + C で止める

質問のしかた

エラーを人や AI に相談するときは、①何をしようとしたか ②打ったコマンド ③表示されたエラーの全文をセットで伝えると、すぐに原因が見つかります。エラーは画像ではなく、文字のままコピーして貼りましょう。

注意

ネットや AI が教えてくれたコマンドでも、sudo や rm -rf が入っているものは、意味がわかるまで実行しないでください。PC の大事なファイルを消してしまうことがあります。
